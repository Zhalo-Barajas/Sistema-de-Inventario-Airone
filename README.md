# Sistema de Inventario Airone
Sistema Correspondiente a mi proyecto de Tesis de Licenciatura Para obtener el título de Licenciado en Ciencias Computacionales:

_SISTEMA DE INVENTARIO PARA EL ÁREA ACADÉMICA DE INGENIERÍA Y ARQUITECTURA: AIRONE._

## Creado por Diego Ángel Barajas Pérez 

**Sistema Web desarrollado con el propósito de:**

Facilitar la gestión y consulta de información del inventario del Área Académica de Ingeniería y Arquitectura mediante la implementación de tecnología web para su uso por parte del personal administrativo y prestadores en ejercicio de servicio social de esta área.
